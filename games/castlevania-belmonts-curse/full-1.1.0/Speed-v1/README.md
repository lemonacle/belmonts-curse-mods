# Speed v1 — full game 1.1.0

Doubles Rose's normal locomotion speed. Enemy movement and global game timing are unchanged. Speed bonuses apply before the 2x multiplier.

Compatibility: title ID `0100BA4026E94000`, executable build ID `0F1169AA7D0FA4529C861F96ADEC306E`. Emulator `.pchtxt` support required; native Switch hardware is not validated.

Extract the ZIP and copy the `Speed-v1` folder into the game's mod directory. Enable it and fully restart. Disable and restart to restore normal movement. Installation does not edit saves or persistent speed settings.

Independent of NG+, 4:3, RenderScale Fix and Manual Zoom. Static instruction checks passed. Patch ranges do not overlap NGPlus-v14 or the released display components. In-game verification of Speed v1 has not been recorded.
